# Запуск закрытой беты

Инструкция для одного сервера: VPS, Docker, свой домен, HTTPS
от Let's Encrypt. На всё уходит около получаса, из них большая часть —
ожидание, пока DNS-запись разойдётся.

Что получится в итоге:

- приложение по адресу `https://ваш-домен` — ставится на экран «Домой»
  iPhone, работает без сети, присылает напоминания;
- регистрация только по приглашениям: вы создаёте код прямо в приложении
  и отправляете тестеру ссылку;
- новый тестер после регистрации проходит короткий опрос, и приложение
  настраивается под него само.

---

## 1. Что понадобится

| Что | Зачем | Пример |
|---|---|---|
| VPS с Ubuntu 22.04/24.04, 2 ГБ RAM, 20 ГБ диска | здесь будет работать приложение | Timeweb Cloud, Selectel, Hetzner, Beget — от ~300 ₽/мес |
| Домен или поддомен | HTTPS без домена не выдаётся, а без HTTPS iPhone не установит приложение | `tworld.ru`, `beta.вашсайт.ru` или бесплатный `имя.duckdns.org` |

## 2. DNS

В панели регистратора домена создайте **A-запись**: имя домена →
IP-адрес сервера. Проверить, что запись заработала:

```bash
ping tworld.example.ru     # должен ответить IP вашего сервера
```

## 3. Сервер

Зайдите на сервер по SSH и поставьте Docker:

```bash
curl -fsSL https://get.docker.com | sh
```

Заберите код:

```bash
git clone https://github.com/Raffilach/TWORLD_CL.git tworld
cd tworld
```

## 4. Настройки

```bash
cp .env.prod.example .env.prod
nano .env.prod
```

Обязательно заполнить три строки:

- `DOMAIN` — ваш домен без `https://`;
- `DJANGO_SECRET_KEY` и `POSTGRES_PASSWORD` — длинные случайные строки:

  ```bash
  python3 -c "import secrets; print(secrets.token_urlsafe(50))"
  ```

`.env.prod` содержит секреты и в git не попадает.

## 5. Запуск

```bash
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build
```

Первая сборка — 3–5 минут. Когда закончится, откройте `https://ваш-домен`:
сертификат Caddy получит сам за несколько секунд.

Создайте свой аккаунт администратора:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.prod \
  exec backend python manage.py createsuperuser
```

Войдите в приложение с этим ником и паролем. Администратор регистрируется
в обход приглашений.

## 6. Приглашения

**В приложении:** Профиль → «Пригласить тестеров» → «Создать приглашение».
Откроется меню «Поделиться» — отправьте ссылку в Telegram или WhatsApp.
Тестер откроет её, и регистрация начнётся с уже подставленным кодом.

Один код можно выдать одному человеку или сразу на группу (до 5 или до 20
регистраций). Там же видно, кто по какому коду зарегистрировался, и можно
отозвать неиспользованный код.

**Из консоли** — если удобнее раздать пачку:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.prod \
  exec backend python manage.py invites create --count 10 --note "волна 1"
```

Открыть регистрацию для всех: `REGISTRATION_INVITE_ONLY=False` в `.env.prod`
и перезапуск (шаг 7).

## 7. Обновление

```bash
cd tworld
git pull
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build
```

Миграции базы применяются сами при старте. Тестерам ничего делать
не нужно: приложение обновится при следующем открытии.

## 8. Резервная копия

Всё ценное — в базе и в загруженных фото. Копия базы:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.prod \
  exec db pg_dump -U tworld tworld | gzip > backup-$(date +%F).sql.gz
```

Разумно поставить эту команду в cron раз в сутки и хранить копии не на том же
сервере.

## 9. Уведомления (по желанию)

Напоминания «взвеситься утром» и «пора спать» работают через web-push.
Сгенерируйте ключи и впишите их в `.env.prod`, затем перезапустите (шаг 7):

```bash
docker compose -f docker-compose.prod.yml --env-file .env.prod \
  run --rm backend python manage.py generate_vapid_keys
```

На iPhone уведомления приходят, только если приложение добавлено на экран
«Домой» (Safari → «Поделиться» → «На экран Домой»).

---

## Как это устроено

| Контейнер | Что делает |
|---|---|
| `web` | Caddy: HTTPS-сертификат, раздача собранного фронтенда, проксирование `/api` и `/admin` в бэкенд |
| `backend` | Django под gunicorn; при старте — миграции, справочники, статика |
| `scheduler` | раз в 5 минут отправляет web-push напоминания |
| `db` | PostgreSQL 16; наружу не открыт |

Защита на бете:

- регистрация только по коду; одноразовый код нельзя использовать дважды,
  даже если два человека нажмут «Создать аккаунт» одновременно;
- лимиты по IP: 10 попыток входа в минуту, 10 регистраций в час,
  5 сбросов пароля в час;
- загруженные фото и голосовые заметки лежат под случайными именами
  (128 бит) — ссылку нельзя подобрать;
- без заданного `DJANGO_SECRET_KEY` бэкенд в продакшне не запустится;
- база наружу не открыта, HTTPS обязателен (HSTS).

Логи, если что-то пошло не так:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.prod logs -f backend web
```
