# TWORLD

Личное PWA-приложение для трекинга тренировок, вредных привычек и дневника.

> **Статус:** проектирование. Код ещё не написан — сначала утверждается схема данных и структура экранов.

## Планируемый стек

Django + DRF + PostgreSQL · React + Vite + TypeScript · PWA (Service Worker + IndexedDB) · WeasyPrint для PDF · MCP-сервер отдельным модулем.

Всё оформление — в одном файле CSS-переменных (`frontend/src/styles/tokens.css`) с нейтральными заглушками.
