# TWORLD_CL — Мышечная карта нагрузки

Детализированная интерактивная анатомическая карта мышц (вид спереди и сзади) с **трёхцветной шкалой нагрузки**:

| Цвет | Зона | Тренировка | Неделя |
|---|---|---|---|
| 🟢 зелёный | низкая | < 3 эфф. подх. | < 6 эфф. подх. |
| 🟡 жёлтый | средняя | 3–6 | 6–12 |
| 🔴 красный | высокая | ≥ 6 | ≥ 12 |

Пороги можно менять прямо в интерфейсе.

## Запуск

Сборка не нужна — это статическая страница без зависимостей.

```bash
python3 -m http.server 8000   # затем откройте http://localhost:8000
```

Или просто откройте `index.html` в браузере. Страница подходит для GitHub Pages.

## Возможности

- **44 мышцы в 16 группах**: три части трапеции, три пучка дельт, три части большой грудной, три головки трицепса,
  вращательная манжета, ромбовидные, большая круглая, передняя зубчатая, все головки квадрицепса и задней поверхности бедра,
  приводящие, портняжная, мышцы голени и предплечья и др. У каждой есть русское и латинское название и описание функции.
- **Конструктор тренировки**: 71 упражнение в библиотеке с поиском и фильтром, 8 готовых программ
  (фулбоди, push/pull/legs, верх/низ, кор, недельный сплит). Подходы меняются кнопками «−/+».
- **Расчёт нагрузки** в эффективных подходах: основная мышца × 1, вспомогательная × 0,5, стабилизатор × 0,25.
- **Ручная разметка**: кисть с тремя уровнями и ластиком, заливка целой группы, копирование из конструктора.
- **Заливка «Зоны» или «Градиент»**: три чётких цвета или плавный переход зелёный → жёлтый → красный.
- **Подсветка при наведении**: если навести курсор на упражнение, на карте выделяются задействованные мышцы
  (сплошная обводка — основные, пунктир — вспомогательные, точки — стабилизаторы).
- **Карточка мышцы**: вклад каждого упражнения в её нагрузку и подходящие упражнения, которые можно добавить одной кнопкой.
- **Сводка по группам** с распределением нагрузки по зонам и счётчики мышц в каждой зоне.
- **Экспорт в PNG** (обе проекции, сводка по группам и легенда), светлая и тёмная тема, адаптивная вёрстка,
  управление с клавиатуры. Состояние сохраняется в `localStorage`.

## Структура

```
index.html        — разметка страницы
css/styles.css    — стили, светлая и тёмная тема
js/anatomy.js     — SVG-геометрия мышц (рисуется левая половина, правая отражается зеркально)
js/data.js        — мышцы, группы, упражнения, программы, пороги шкал
js/app.js         — расчёт нагрузки, отрисовка, взаимодействие, экспорт
```

Чтобы добавить упражнение, допишите объект в `EXERCISES` (`js/data.js`) и укажите в нём основные (`p`),
вспомогательные (`s`) мышцы и стабилизаторы (`t`).
