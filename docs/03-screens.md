# 03. Структура экранов и UX-механика

Документ описывает **структуру и взаимодействие**, не внешний вид. Любое упоминание размера/цвета — это имя токена, а не значение.

---

## 3.1 Бюджет ввода — контракт, а не пожелание

Правило из задания: **> 3 сек или > 2 тапов = переделать**. Считаем тапы явно по каждому частому действию.

| Действие | Тапов | Как именно |
|---|---|---|
| Записать утренний вес | **2** | тап по цифре веса на «Сегодня» → сразу системная цифровая клавиатура с прошлым значением в placeholder → ввод → автосохранение по blur. **Нет** кнопки «Сохранить», модалки, слайдера, колеса |
| +1 стакан воды | **1** | тап по кружку-счётчику |
| Отметить креатин | **1** | тап по чекбоксу |
| Настроение / энергия | **1** | шкала 1–5 нарисована пятью кнопками сразу, не за модалкой |
| Записать подход (как в прошлый раз) | **1** | «✓ 62,5 × 10» — кнопка сразу с предзаполненными значениями |
| Записать подход с правкой веса | **2** | −/+ по сетке зала → «✓» |
| Зафиксировать попытку планки | **1** | «Зафиксировать» — таймер **продолжает идти**, попытка уходит в список |
| Белок: частый продукт | **1** | тап по быстрой кнопке |
| Сон за ночь | **2** | два поля `type="time"` с подставленными вчерашними значениями |
| Начать тренировку | **1** | «Начать» на «Сегодня», план уже открыт |
| Отметить срыв привычки | **2** | тап по привычке → «отметить эпизод» (вопрос «что случилось» — **необязательный**) |

Всё, что не влезает в бюджет, уезжает в «подробнее», но **не блокирует** основной путь.

## 3.2 Навигация

Нижний таб-бар, 5 вкладок, фиксирован, `padding-bottom: env(safe-area-inset-bottom)`.

```
┌─────────────────────────────────────────┐
│  контент (scroll)                       │
│                                         │
├─────────────────────────────────────────┤
│ Сегодня │Трениров.│Прогресс│Друзья│Профиль│  ← 44×44 pt минимум на таб
└─────────────────────────────────────────┘   ← safe-area-inset-bottom
```

- Свайп вправо от левого края — назад (как системный жест).
- Свайп влево/вправо по контенту «Сегодня» — предыдущий/следующий день.
- Активная тренировка живёт **над** таб-баром компактной плашкой на всех вкладках («Тренировка идёт · 34:12 · отдых 0:45») — вернуться в неё можно откуда угодно одним тапом.

## 3.3 Вкладка «Сегодня» — главный экран

Реестр блоков (порядок и видимость настраивает пользователь, хранится в `UserSettings.today_blocks`):

| block_id | Блок | По умолчанию |
|---|---|---|
| `weight` | Вес утром | вкл |
| `workout` | Тренировка сегодня | вкл |
| `quick_checks` | Добавки / вода / белок | вкл |
| `habits` | Счётчики привычек | вкл |
| `sleep` | Сон за прошлую ночь | вкл |
| `mood_energy` | Настроение и энергия | вкл |
| `day_progress` | Прогресс дня | вкл |
| `journal_quick` | Быстрая запись в дневник | выкл |
| `measurements_due` | Замеры по расписанию | выкл |
| `photo_due` | Прогресс-фото по расписанию | выкл |
| `evening_plan` | «Выйти из зала до 21:10» | вкл в дни тренировок |

Порядок правится перетаскиванием в режиме редактирования (кнопка «Настроить» в шапке), лишнее скрывается там же.

### Блок «Вес»
```
┌──────────────────────────────────┐
│ Вес утром                        │
│                                  │
│   [  82,4  ] кг   ← тап = ввод   │
│   тренд 82,9 · −0,3 за неделю    │
│                                  │
│   ○ утро ○ натощак ○ без одежды  │  ← условия замера, запоминаются
└──────────────────────────────────┘
```
- `inputMode="decimal"`, `font-size: 16px` минимум (иначе Safari зумит), placeholder = вчерашнее значение.
- Автосохранение через 800 мс после последнего ввода + по blur. Появляется «Отменить» на 5 секунд.
- Условия замера — чипы с памятью прошлого выбора, тапать не обязательно.
- Записанный вес **сразу** заменяется трендом крупно, сырое значение — мелким.

### Блок «Тренировка сегодня»
- Есть по плану → `[ Начать ]` крупной кнопкой в нижней трети + список упражнений блока `required` свёрнуто.
- Нет по плану → «Следующая: пн, Верх тела» + `[ Начать сейчас ]` (можно потренироваться вне плана).
- Тренировка уже сделана → сводка: тоннаж, длительность, самочувствие, новые рекорды.

### Блок «Быстрые галочки»
```
Добавки   [✓ креатин] [ омега ] [ витD ]     ← 1 тап, серия «12 дней» мелким
Вода      ●●●●●○○○  5 / 8 стаканов  [+]      ← тап по [+] или по пустому кружку
Белок     ▓▓▓▓▓▓░░░░ 96 / 150 г              ← тап открывает быстрые продукты
```
Быстрые продукты — горизонтальный ряд кнопок «Творог 18 г», «Протеин 24 г», «Курица 31 г»; тап = запись. Последняя кнопка — «＋» (добавить/найти/штрихкод).

### Блок «Привычки» (компактный)
Только текущие серии, по строке на привычку: `Без сахара · 12 дней · 340 дней с решения`. Тап — на подробный экран. Кнопка `SOS` присутствует всегда, но нейтрально.

### Блок «Сон»
Если пришло из Health — показано как факт с пометкой источника. Если нет — два поля времени (`type="time"`), предзаполненные привычными значениями: `Отбой 23:40  Подъём 07:10 → 7 ч 30 мин`.

### Блок «Настроение и энергия»
Две строки по 5 кнопок. Тап — сохранение. Без подписей «плохо/хорошо» с оценочной окраской, только числа и нейтральные иконки-токены.

### Блок «Прогресс дня»
`Отмечено 5 из 7` + полоса. Пустые пункты — **нейтрально-серые**, без красного, без восклицательных знаков, без текста «ты пропустил». Под полосой — одна поддерживающая строка, если день пустой: «Ещё есть время. Или не сегодня — это тоже нормально.»

## 3.4 Вкладка «Тренировки»

```
Тренировки
├── Сегодня / Ближайшая        → запуск сессии
├── Программы
│   └── Шаблон
│       ├── Блоки: [обязательный] [основной] [по остатку сил]
│       ├── Упражнения — drag&drop между блоками и внутри блока
│       ├── Оценка длительности: ~62 мин (лимит 60) ⚠ мягкое предупреждение
│       ├── «Сегодня НЕ делаем» — список с причинами
│       └── Расписание по дням недели
├── Библиотека упражнений
│   └── Карточка упражнения
│       ├── Мышцы (первичные/вторичные), оборудование, тип нагрузки
│       ├── Флаг «одностороннее» (вес на одну руку)
│       ├── Профиль по залам: сетка весов, № тренажёра, настройки, фото
│       ├── Альтернативы («тренажёр занят»)
│       ├── История: график веса и повторов, ЛР с датой
│       └── Лимит веса с причиной (из раздела «Травмы»)
├── История тренировок        → список сессий, фильтры
└── Залы                      → рабочий / домашний / в поездке
```

### Экран активной тренировки — вторая по важности точка после «Сегодня»

```
┌──────────────────────────────────────┐
│ Верх тела · 34:12        [Завершить] │
│ ▓▓▓▓▓▓░░░░ обязательный блок 4/6     │
├──────────────────────────────────────┤
│ ОБЯЗАТЕЛЬНЫЙ                          │
│ ✓ Жим лёжа        62,5×10 62,5×9 …   │
│ ▸ Тяга блока      ← текущее           │
│     подход 1  62,5 кг × 10   RIR 2 ✓ │
│     подход 2  [ −  62,5  + ] [ 10 ]  │
│                  ↑ шаг по сетке зала  │
│     [ ✓ Записать ]  [ Как в прошлый ] │
│     ⚠ лимит 63 кг — спина             │
│ ○ Разведения                          │
│ ОСНОВНОЙ                              │
│ ○ Молотки (на руку)                   │
│ ПО ОСТАТКУ СИЛ                        │
│ ○ Планка                              │
├──────────────────────────────────────┤
│ Отдых 1:12 ▓▓▓▓▓░░  [+30с] [Пропустить]│  ← липкая плашка внизу
└──────────────────────────────────────┘
```

Механика:
- **Предзаполнение прошлыми значениями** — открыл упражнение, веса уже стоят с прошлого раза в этом зале.
- **«Как в прошлый раз»** копирует все подходы упражнения целиком одним тапом.
- **−/+ ходят по `weight_steps` конкретного зала**: 45,3 → 49,8 → 54,4. Долгий тап — выбор из полного списка сетки.
- **Разминочные** помечаются переключателем «Р» на строке подхода, визуально приглушены, в рабочий тоннаж не идут.
- **RIR** — опциональный ряд 0–4, показывается только если включён в настройках.
- **Свайп по строке подхода влево** — удалить (с отменой).
- **Три состояния упражнения** — долгий тап или свайп вправо: `Сделано` / `Пропустить` / `Не смог`. «Не смог» → список причин в один тап: тренажёр занят / нет сил / боль / не хватило времени / забыл. Причина «тренажёр занят» тут же предлагает **альтернативу** из списка упражнения.
- **Таймер отдыха** стартует автоматически после записи подхода, пресет — из упражнения (60–90 изоляция, 120 тяги/жимы). Считается по стенным часам, переживает блокировку экрана; при возврате — верное значение; уведомление через Service Worker.
- **Основные кнопки — в нижней трети** экрана (зона большого пальца).
- Всё пишется в IndexedDB мгновенно; сеть не требуется.

### Секундомер статики (планка, вис)
```
┌────────────────────────┐
│        01:07           │  ← крупно, моноширинные цифры (токен)
│  [ Зафиксировать ]     │  ← НЕ обнуляет, создаёт попытку и считает дальше
│  [ Пауза ] [ Сброс ]   │  ← сброс отдельно и явно
│  Попытки: 74 с · 68 с  │  ← каждая отдельной строкой, свайп для удаления
│  Ручной ввод: [ 85 ] с │  ← подсказка «85 = 1:25»
└────────────────────────┘
```
Попытка < 2 с не сохраняется молча: «Записать 1 с?» с отменой. Формат хранения — целые секунды, всегда.

### Подсказки прогрессии (ненавязчивые, в карточке упражнения)
- «Все подходы в верхе диапазона, RIR ≥ 2 → попробуй 58,9 кг» (следующий шаг сетки).
- «+14% за неделю — связки адаптируются медленнее мышц. Может, задержаться на этом весе?»
- «3 недели без прогресса — сменить схему?»
- «Пропущено 6 раз подряд. Поставить в начало тренировки?» → кнопка сразу переставляет.

## 3.5 Вкладка «Прогресс»

```
Прогресс
├── Обзор недели: тренд-вес, тоннаж, сон, белок, серии — карточками
├── Вес и состав тела
│   ├── График: тренд (жирная линия) + сырые точки (бледные) + метки событий
│   ├── Замеры сантиметром (талия — первой)
│   ├── Анализатор состава (InBody): ввод, история по каждому показателю, фото листка
│   └── Прогноз: «до 12% жира ≈ 9 недель при текущем темпе»
├── Тренировки: тоннаж по неделям, объём по группам мышц, дисбаланс push/pull, рекорды
├── Сон: длительность, попадания в отбой, долг сна, ★ график «сон → самочувствие»
├── Привычки: таймлайны с точками срывов, карта триггеров, экономия денег
├── Питание: белок по дням, исключения за неделю (сладкие напитки отдельной строкой)
├── Аналитика
│   ├── Корреляции (с n и оговоркой «связь ≠ причина»)
│   ├── ★ Слабое звено недели — ОДНА метрика + один фокус на следующую неделю
│   ├── Сравнение двух недель/месяцев бок о бок
│   ├── Календарь-теплокарта за год
│   └── Нормативы: планка, подтягивания, бег — статус и прогноз
└── Недельный отчёт → PDF (подробный «для тренера» / короткий «для себя»),
                       «Скопировать для ИИ», публичная ссылка
```

На **всех** графиках — вертикальные линии `LifeEvent` (травма, поездка, болезнь, экзамен) с подписью. Провал получает объяснение вместо самобичевания.

## 3.6 Раздел «Травмы и безопасность» (внутри «Прогресс» + быстрый вход из тренировки)

- **Карта тела**: SVG спереди/сзади, тап по зоне → выбор стороны → интенсивность 1–10 ползунком-шкалой из 10 кнопок (не слайдером — слайдер это точность, которой нет).
- После сохранения — сразу список затронутых упражнений с метками «осторожно» и кнопкой «исключить на время».
- **Лимиты веса**: `Скручивания ≤ 63 кг — спина`. При вводе большего в зале — плашка с причиной прямо над кнопкой «Записать». Не блокирует.
- **Тест возврата**: перед разблокировкой — один вопрос «Болит при движении без веса?» Да → остаётся заблокировано, предложение более лёгкой альтернативы.
- **Рецидив**: вторая травма той же зоны за 60 дней → постоянная (не исчезающая сама) карточка с рекомендацией к врачу. Формулировка серьёзная, но без драматизма.
- «Тренировка на больном» — переключатель при старте сессии; такие сессии считаются отдельно и видны на графиках.

## 3.7 Вкладка «Друзья» — осознанная заглушка

Не «404», не «coming soon» мелким шрифтом, не замочки.

```
┌──────────────────────────────────┐
│                                  │
│        [графический блок]        │  ← SVG-композиция на токенах,
│                                  │     структура есть, оформление — позже
│      Друзья появятся здесь       │
│                                  │
│  • Делиться прогрессом — тем,    │
│    что сам выберешь              │
│  • Сравнивать серии привычек     │
│  • Совместные челленджи          │
│  • Реакции на тренировки друзей  │
│                                  │
│  [ Сообщить, когда появится ]    │  → FeatureInterest(user, 'friends')
│                                  │
│  Твой ник: @raffilach   [копир.] │  ← уже полезно: по нему найдут
│                                  │
│  Что ещё было бы полезно?        │
│  [____________________] [→]      │  → FeatureInterest(..., 'suggestion', message)
└──────────────────────────────────┘
```
После нажатия кнопка меняется на «Сообщим» и остаётся активной для отмены. Никаких намёков на платность.

## 3.8 Вкладка «Профиль»

```
Профиль
├── @username (проверка занятости в реальном времени + подсказки свободных)
├── Display name, аватар (загрузка / заглушка из инициалов)
├── Личное: пол, дата рождения, рост, стартовый вес, часовой пояс, единицы, язык
├── Цели: целевой вес, % жира, дедлайн
├── Экран «Сегодня»: состав и порядок блоков
├── Тренировки: залы, пресеты отдыха, спрашивать ли RIR
├── Питание: цель по белку, вода, ★ «Считать калории» — ВЫКЛ по умолчанию
├── Сон: цель отбоя, время дороги домой, время на сборы
├── Уведомления: не больше 2 в день, все переключатели, тихие часы
├── Приватность: пин/биометрия на дневник
├── Интеграции
│   ├── Apple Health (Shortcut, импорт export.zip, нативная обёртка)
│   ├── API-токены (read / write, отзыв)
│   ├── Публичные ссылки на отчёты (список + отзыв)
│   └── MCP-сервер: адрес и токен
├── Данные: экспорт JSON / CSV, импорт плана от ИИ
└── Аккаунт: смена пароля, выход, удаление аккаунта со всеми данными
```

Проверка username: дебаунс 300 мс, `GET /api/accounts/username-available/?u=`, при занятости — 3 свободных варианта (`raffilach_1`, `raffilach_gym`, `raffi_lach`).

Удаление аккаунта: одна кнопка → подтверждение вводом `@username` → мгновенное каскадное удаление + удаление файлов. Перед этим предлагается экспорт.

## 3.9 Мобильные требования — чеклист реализации (раздел 14)

| Требование | Как выполняется |
|---|---|
| PWA | `manifest.webmanifest`, иконки 120/152/167/180/192/512, `apple-touch-icon`, сплэши под все размеры iPhone, `display: standalone` |
| Safe area | `--safe-top/right/bottom/left: env(safe-area-inset-*)`, таб-бар и липкие плашки используют их |
| Тап-зоны | Токен `--tap-min: 44px`; линтер-тест в Playwright проверяет размеры интерактивных элементов |
| **16px в input** | Глобально `input, select, textarea { font-size: max(16px, var(--font-size-body)); }` — иначе Safari зумит при фокусе |
| Клавиатуры | вес `inputMode="decimal"`, повторы/секунды `inputMode="numeric" pattern="[0-9]*"`, время `type="time"`, ник `autocapitalize="off" autocorrect="off"` |
| Масштабирование | `user-scalable` **не отключаем** |
| Зона большого пальца | Первичные действия в нижней трети; шапка — только заголовок и вторичное |
| Свайпы | назад от края; влево по строке подхода — удалить; влево/вправо по «Сегодня» — смена дня |
| Hover | Никогда как единственный способ; все состояния дублируются `:active` / `:focus-visible` |
| Скролл | `-webkit-overflow-scrolling: touch`, `overscroll-behavior: contain` на липких областях, `touch-action: pan-y` на свайп-строках |
| Оффлайн | Service Worker + IndexedDB + очередь; тренировка полностью работает без сети |
| Автосохранение | Каждое поле само; кнопки «Сохранить» нет; «Отменить» на 5 секунд после каждого автосохранения |
| Haptics | `navigator.vibrate` где поддерживается (Android) + Haptic API в нативной обёртке |
| Тёмная тема | `prefers-color-scheme` переопределяет токены |
| Адаптив | 320–430 телефон (одна колонка) · 431–1023 планшет (две) · ≥1024 десктоп (три колонки: навигация + контент + контекст-панель, **не растянутый мобильный**) |

## 3.10 Уведомления (раздел 15)

Максимум 2 в день по умолчанию, каждое отключается отдельно.

| Когда | Текст (нейтральный, без укора) | Действие из уведомления |
|---|---|---|
| Утро | «Доброе утро. Взвесишься?» | поле ввода прямо в уведомлении (Notification Actions) |
| За 30 мин до отбоя | «Через 30 минут — целевое время отбоя» | «Отложить на 15 мин» |
| Персональное рисковое время | «Обычно в это время бывает тяга. Заменители под рукой.» | открыть SOS |

Запрещённые формулировки зашиты в код-ревью чеклист: «ты пропустил», «снова», «опять», «не забыл ли», «ты обещал», восклицательные знаки в упрёк.
