# 04. Вопросы к утверждению

У каждого вопроса есть **выбранный по умолчанию ответ**. Если промолчишь — делаю по умолчанию, ничего не блокируется.

---

### 1. Порядок сборки
**По умолчанию:** бэкенд целиком (модели → миграции → API → сиды → OpenAPI) → фронтенд «Сегодня» + «Тренировки» → остальные вкладки → PDF → оффлайн → MCP.
**Альтернатива:** вертикальный срез — сначала сквозной путь «Сегодня + активная тренировка» (бэк+фронт), чтобы пощупать главный сценарий через пару дней, а не в конце.

---

### 2. Нативная обёртка
**По умолчанию:** сейчас только PWA. Apple Health — через Apple Shortcuts + вебхук (работает сразу, без App Store). Схема БД уже готова к нативу.
**Почему это важно:** без обёртки не будет надёжного звука таймера при заблокированном экране, виджетов и Live Activities. Если они нужны сразу — это отдельный этап на Capacitor + Swift-плагин.

---

### 3. «Тренировка выполнена» — только обязательный блок?
**По умолчанию:** день засчитан, если закрыт блок `required`. `main` и `optional` показываются как бонус.
Спрашиваю, потому что от этого зависит вся статистика дисциплины.

---

### 4. Причины «не смог», не портящие дисциплину
**По умолчанию не портят:** тренажёр занят, боль, не хватило времени, болезнь.
**По умолчанию портят:** нет сил, забыл, другое.
«Нет сил» — спорный случай: это может быть как лень, так и недовосстановление. Переключается в настройках в любом случае.

---

### 5. Тренд-вес: SMA-7 или EMA?
**По умолчанию:** скользящее среднее за 7 дней (как в задании), минимум 2 точки, пропуски интерполируются.
EMA реагирует быстрее на реальные изменения, но сильнее прыгает. Могу отдавать оба и дать переключатель.

---

### 6. Штрихкоды и база продуктов
**По умолчанию:** сканирование через `BarcodeDetector` (Safari 17+) с фолбэком на библиотеку; данные — Open Food Facts (бесплатно, без ключа), сохраняются в личную базу продуктов.
Если нужна российская база с точными данными — это платные API, нужен твой выбор поставщика.

---

### 7. Голосовые заметки
**По умолчанию:** запись всегда работает; расшифровка — опциональная, через Whisper API, ключ в переменных окружения. Нет ключа — заметка хранится как аудио, без ошибок и заглушек.

---

### 8. Язык интерфейса по умолчанию
**По умолчанию:** ru, полный i18n-каркас с самого начала (не дописывать потом), en — вторым.

---

### 9. Деплой
**По умолчанию:** `docker-compose` (postgres + backend + frontend + nginx), README под VPS. Если целевая площадка другая (Railway / Fly / Яндекс.Облако / свой сервер) — скажи, подгоню конфиги и инструкции.

---

### 10. Демо-данные
**По умолчанию:** сид на 90 дней для одного демо-пользователя, включающий «интересные» случаи для проверки экранов: срыв привычки, травма плеча с рецидивом, скачок веса +14% за неделю, застой на 3 недели, неделя с недосыпом, пропуск упражнения 6 раз подряд. Иначе половину логики визуально не проверить.
